# 독서 - 나만의 책장

책 이름, 책 내용, 책 사진을 기록하는 반응형 독서 앱입니다.

- **화면**: GitHub Pages (`index.html`)
- **저장소**: Google Apps Script → 구글 스프레드시트(책 정보) + 구글 드라이브(사진)

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 화면 전체 (입장, 책장, 등록·수정, 상세) |
| `manifest.webmanifest` | 홈 화면에 앱으로 추가하기 위한 정보 |
| `sw.js` | 앱 화면을 기기에 저장해 다음부터 즉시 열기 |
| `icons/` | 앱 아이콘, 파비콘 |
| `Code.gs` | 구글 스크립트에 붙여 넣을 서버 코드 (GitHub에는 참고용) |

## 설정 순서

### 1. 구글 스크립트 (데이터 저장)
1. script.google.com → **새 프로젝트** → `Code.gs` 내용 붙여 넣기
2. 맨 위 `APP_KEY` 를 나만 아는 비밀번호로 변경
3. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (GitHub 화면에서 접속하려면 필요. 비밀번호로 보호됩니다)
4. 권한 승인 후 나오는 **웹 앱 URL** (`…/exec`) 복사

### 2. GitHub (화면)
1. `index.html` 의 `const API_URL = '';` 따옴표 안에 웹 앱 URL 붙여 넣기
2. 새 저장소를 만들고 이 폴더의 파일을 모두 업로드
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 으로 접속 → 비밀번호 입력 후 입장

### 휴대폰 홈 화면에 추가
- 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
- 안드로이드(Chrome): 메뉴 → **홈 화면에 추가** 또는 **앱 설치**

## 참고
- `API_URL` 을 비워 두면 **미리보기 모드**(이 기기에만 저장)로 동작합니다.
- `Code.gs` 를 고친 뒤에는 **배포 관리 → 수정 → 버전: 새 버전**으로 다시 배포해야 반영됩니다. (주소는 그대로 유지)
- `index.html` 을 고친 뒤에는 `sw.js` 의 `CACHE = 'reading-v1'` 숫자를 올리면 모든 기기에 바로 반영됩니다.
